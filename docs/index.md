# CipherStream Pro

CipherStream Pro is a hybrid cryptographic application that pairs a Java backend with a Streamlit frontend. It works at the byte level, so it can process simple sentences, emojis, and multi-language text.

[Open the live demo](https://cipherstream-pro-5uqutxcjur3ifz9mbircs3.streamlit.app/){ .md-button }

!!! note "Educational project"
    A byte-shift cipher is not secure by modern standards. Do not use CipherStream Pro to protect sensitive data.

## What you can do

- Generate a security key (`vault.key`) and download it.
- Lock a message, including emojis and symbols, and download it as `message.enc`.
- See a Digital Fingerprint and a Vault Health Check chart for your locked message.
- Restore the original message with your key and your locked message file.
